# Merin John — Frontend Developer Portfolio

A modern, responsive developer portfolio built with **React.js, Vite, and Tailwind CSS** to showcase my skills, projects, and frontend development journey.

**Live Portfolio:** https://merin-john-portfolio.vercel.app/

* Responsive design for desktop, tablet, and mobile

* Animated profile section and interactive UI elements

## Featured Projects

### DevSpace — Blog Platform

A modern responsive blog platform featuring article search, category filtering, dynamic routing, bookmarks, post creation, and LocalStorage-based persistence.

**Tech:** React.js, JavaScript, Tailwind CSS, React Router, LocalStorage

### Weather Dashboard

A responsive weather application displaying current weather information and a 5-day forecast using the OpenWeatherMap API.

**Tech:** React.js, Tailwind CSS, Vite, OpenWeatherMap API

### To-Do List

A modern task management application with a responsive dark interface and LocalStorage support for persistent tasks.

**Tech:** React.js, Tailwind CSS, LocalStorage

### Movie Search

A movie discovery application using the OMDb API with search functionality, debouncing and a responsive interface.

**Tech:** React.js, OMDb API, CSS, JavaScript

## Getting Started

### Clone the repository

```bash
git clone https://github.com/Merinjohnv/merin-john-portfolio.git
```

### Navigate to the project

```bash
cd merin-john-portfolio
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

The application will be available at the local development URL provided by Vite.
